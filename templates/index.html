What gets downloaded?

This tool saves only the HTML document returned for the URL. A webpage usually also relies on CSS stylesheets, JavaScript files, images, fonts and API responses that are fetched separately by the browser — those are not downloaded, so the saved file may look unstyled or incomplete when opened offline.

In Raw HTML mode, content that the page builds with JavaScript after loading will be missing. Rendered DOM mode (when enabled) captures the HTML after scripts run, but still does not save the separate asset files.

Only public http/https sites can be fetched; private and local network addresses are blocked. The tool does not bypass logins, CAPTCHAs or paywalls — please respect each site's terms of use. Size limit: {{ (app_config.max_download_bytes / 1048576) | round(1) }} MB.
