Programme Importer

Build UK Master's and Bachelor's programme datasets from pages you save while browsing Mastersportal and Bachelorsportal.

How it works

  1. Open the listing pages and programme pages in your normal browser (lists of pages still to save are below).
  2. Save each one with Ctrl+S into the import folder for its category.
  3. Press Start import. Listing pages are processed first, then programme pages; results are written to one JSON file per university in the export folder (by default UK/<category>/programs).

The importer never contacts the portals. Mastersportal and Bachelorsportal block automated access, and this tool does not try to get around that: pages showing a Cloudflare or CAPTCHA check are reported as blocked and must be saved again from a normal browser session.
