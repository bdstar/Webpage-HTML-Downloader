Universities Importer

Build one JSON file per university from university profile pages you saved while browsing Mastersportal and Bachelorsportal.

How it works

  1. Open a university's profile page in your normal browser and save it with Ctrl+S into the import folder.
  2. Choose the category the pages belong to and press Start Import.
  3. Each page is read locally, checked, and written to a folder for the university's country inside the export folder: export\UK\universities\<University>.json for the United Kingdom, export\France\universities\<University>.json for France, and so on. Master's and Bachelor's imports of the same university share one file. Missing values are stored as null; a missing value never erases one saved earlier.

The importer never contacts the portals. Pages that show a Cloudflare or CAPTCHA check are reported as blocked and must be saved again from a normal browser session.
